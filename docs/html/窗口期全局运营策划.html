一、窗口期定性：这一年赚四种钱

利润来源特征载体
① 信息差（最快）知道哪里有货、谁在找货、价格往哪走18 年人脉 + 数据系统 → 背靠背撮合
② 库存差（最大）涨价曲线左侧低吸、右侧出货行情线，吃资金与判断力
③ 渠道差（最稳）海外授权渠道价 vs 国内现货价美国/香港主体采购通道
④ 服务差（最久）缺料期整单配套与替代方案BOM 配套线，行情退潮后留存
核心命题：行情钱是一次性的，客户关系和数据资产是留下来的。窗口关闭那天，手里要同时有现金、客户、数据——这才是"一席之地"。

二、竞争定位：为什么是你（V2.0 新增）

壁垒市场上大多数玩家你的位置
判断力跟风炒货，听消息进场18 年周期经验 + 自有数据系统出信号，左侧进场右侧离场
渠道结构只有华强北/同行调货美国公司接授权渠道 + 香港转口 + 国内现货三轨
获客成本电话陌拜 + 平台开店买流量AI 内容流水线 + 多主体矩阵，边际获客成本趋近于零
风险结构单主体硬扛，一波亏损伤全身六主体隔离：行情亏损不污染旗舰信用

结论：四项中任何一项单拿出来都有人比你强，但四项交叉的组合在中小玩家里极少见——这就是小团队赚大钱的结构性依据。

合规检查清单（V2.0 集中版，逐项过）

税务（窗口期流水暴增，贸易公司是稽查重点）

  • ☐ 各主体业务真实独立，合同/资金/货流/票流四流一致
  • ☐ 不用小规模主体拆分收入；不买单出口、不富余票抵扣
  • ☐ 香港利润留存与分红预先做税务安排（CRS 信息交换在跑）
  • ☐ 月度税负率监控，异常波动提前备好业务解释材料

出口管制（刑事级红线）

  • ☐ 建立管制料黑名单：受 EAR 管制物项（高端 FPGA/GPU/AI 芯片等）一律不经美国公司转售中国受限对象
  • ☐ 每笔美国渠道采购过一遍 ECCN 编码筛查；香港转口同样筛查
  • ☐ 不与实体清单（Entity List）上的买家交易
  • ☐ 只做不受限通用料——这条线干净，利润才拿得安稳

资金（反洗钱红线）

  • ☐ "现款现货"= 对公转账即时到账，不收大额物理现金
  • ☐ 个人卡不过公司货款；跨境结算走正规渠道结汇
  • ☐ 大额异常订单（新客户+大金额+加急）做 KYC 留痕

七、拐点监控仪表盘（V2.0 新增，每周五跑）

指标数据来源预警阈值触发动作
重点型号交期渠道日采集连续 2 周缩短库存水位降至 25% 以下
渠道报价方差多渠道比价库方差收窄 30%+（市场共识形成=行情尾声）停止新开仓
询盘结构CRM 标签"急单/现款"占比跌破 40%配套线接管资源倾斜
原厂/大分销动态公告+情报扩产到位 / 取消配额制公告7 天内库存清至 10% 以下
同行抛货信号同行群+现货平台挂单量挂单量周环比 +50%立即按市价出，不等反弹
仪表盘的意义：把"凭感觉跑"变成"按规则跑"。窗口期死掉的炒家都不是判断错了方向，而是拐点到了舍不得出。

风控铁律（让情景 C 死不了人）

  1. 任何时点库存占用 ≤ 周转资金 50%，另一半永远是现金
  2. 单一型号持仓 ≤ 总资金 15%；单一品类 ≤ 35%
  3. 任何一批货持有 ≤ 4 周，到期无论盈亏必须出
  4. 仪表盘任一红色指标触发 → 按表执行，不开会不讨论
  5. 每周资金复盘会；操盘手对超限持仓一票否决
